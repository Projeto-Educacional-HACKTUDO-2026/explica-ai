# Projeto Explica Aí!



Desafio: Desenvolver soluções inovadoras que permitam a utilização consciente dos smatphones nas escolas integrando tecnologia, metodologias educacionais e estratégias de promoção da Saúde mental.



Ideia: Aplicação que facilita e explora o conhecimento do aluno de forma interativa baseado na tecnica de feyman. O objetivo é o aluno explicar tópicos definidos pelo professor de forma simples mas que demonstram conhecimento.

O app vai ter grande interação entre alunos e professor.



Defesa: Essa solução fortalece o foco do aluno ao usar algo que é raramente utilizado no ensino tradicional que é, a capacidade de descrever sobre um assunto educacional através de suas próprias palavras e pensamentos. Isso vai gerar impacto no seu interesse e também ajudar a reter as informações facilmente com o incentivo do app e suas mecânicas de pontuação.



"O Explica Aí! transforma o celular de fonte de distração em ferramenta de aprendizagem ativa. Usando a técnica de Feynman, o aluno aprende explicando com as próprias palavras, recebe feedback e refaz até dominar o conteúdo. Sessões curtas, notificações controladas e progresso sem ranking tóxico promovem uso consciente do smartphone e bem-estar: o aluno compete apenas com a sua versão de ontem. Para o professor, o app revela quais conceitos a turma ainda não entendeu."



* Requerimentos funcionais:



• Usuários escolhem entre criar uma conta de professor e aluno.

• Professores criam salas.

• Professores criam tópicos.

• Professores podem vincular tópicos a uma sala.

• Professores convidam alunos para participar de uma sala.

• Professores criam desafios dentro de um tópico (texto, imagens, áudio e vídeos).

• Professores podem escolher ou publicar tópicos com desafios públicos, acessível à outros professores na plataforma.

• Professores podem controlar o tempo limite do áudio ou/e de caracteres de um desafio.

• Professores podem eleger alunos monitores em cada sala, capazes de avaliar e controlar desafios como e para um professor.

• Para cada desafio, professores definem prazos em dias (reiniciado toda vez que for adicionado à uma nova sala).

• Professores podem sobrescrever o ganho padrão de XP de um desafio (aumentar ou diminuir).

• Professores podem criar ou personalizar emblemas dentro de uma sala (premiação).

• Alunos aceitam convites para entrar em uma sala.

• Alunos podem editar seus perfis e bios.

• Alunos podem visualizar desafios e seus status dentro dos tópicos da sala (pendente, respondido, avaliado, etc.).

• Alunos executam os desafios criados pelo professor em formato de áudio ou texto corrido, sem possibilidade de apagar caracteres. Apenas reiniciar.

• Sistema concebe uma quantidade X de XP definida no tópico para o aluno.

• Sistema concebe emblemas (ou títulos) à alunos que atingirem metas arbitrárias de XP.

• Sistema constrói um mosaico aos poucos para alunos, baseado no XP atual. O mosaico faz parte de um mosaico maior da turma, que é completo assim que todos obterem o máximo de XP na classe.

• Sistema mostra um dashboard para alunos em sua página inicial com informações sobre quantidade de respostas corretas, erradas, tempo de tela no aplicativo e etc.

• Sistema mostra um dashboard para professores em sua página inicial com informações sobre alunos, classes, respostas corretas e etc.

• Sistema mostra quem avaliou o desafio.

• Sistema notifica desafios publicados para alunos.

• Sistema notifica correções para alunos.

• Sistema notifica respostas de alunos uma vez por dia para professores e monitores.

• Sistema permite escutar áudio em até 2x.

• Alunos informam se usaram IA generativa para gerar o texto da resposta de um desafio.

• Se sim, sistema concebe ganho de XP reduzido (-50% de XP. XP final não pode ser negativo, sendo 0% o mínimo).

• Professores podem visualizar respostas de alunos dentro de uma sala.

• Professores podem corrigir respostas de alunos dentro de uma sala dentro de uma escala de 3 graus: 3 -> Excelente resposta (100% XP ganho), 2 -> Boa resposta (75% XP ganho), 1 -> Pode ser melhor (20% XP).

• Professor pode adicionar um texto para justificar correção.

• Alunos podem refazer desafios que tiraram 3 uma vez.

• Professores e monitores podem controlar a quantidade de vezes que um aluno pode realizar um desafio.

• Alunos podem compartilhar conquistas.

• Alunos podem desafiar outros alunos dentro de uma sala, com as mesmas liberdades de um professor.

• Professores aprovam respostas criadas pelos alunos.



* Requerimentos não-funcionais:



• Autenticação deve ser segura.

• Aplicação deve ser intuitiva e fácil de navegar para todos os tipos de usuários.

• Aplicação deve evitar competição entre alunos, buscar o crescimento individual e adequado à velocidade de cada um.

• Não punitivo.

• Aplicação não deve enviar nenhuma notificação entre 22h e 7h.

• Mobile-first com interface web.
